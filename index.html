第一次使用 GrokX

01

安装桌面客户端

macOS 用户打开 DMG，把 GrokX 拖入「应用程序」。Windows 用户按处理器架构选择 EXE，再运行安装程序。

02

准备一个编程 CLI

在终端安装 Grok Build、OpenCode、CodeBuddy Code、Antigravity CLI 或 Codex CLI。按所选工具的指引登录或配置模型服务，再打开 GrokX。

03

打开项目，开始会话

选择本地项目目录并新建会话。发送第一条消息前，选择要使用的 CLI。助手请求执行命令或修改文件时，可在会话中查看权限提示并决定是否允许。

GrokX 通过 ACP 与本机 CLI 通信。模型、账号和用量由所选 CLI 及其模型服务决定。使用 Codex CLI 还需安装 codex-acp 适配器。

找不到 CLI？

先在终端确认对应命令能运行，例如 grok --version。如果终端也找不到命令，请检查 CLI 是否已安装，以及它的目录是否已加入系统 PATH。安装或调整 PATH 后，完全退出并重新打开 GrokX。

如果能找到 CLI，但会话提示需要登录，请在终端完成认证。例如，Grok Build 可以运行 grok login。
