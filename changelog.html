版本更新记录

从新到旧查看 GrokX 各公开版本的改动和安装包。

  1. v0.28.1

    最新发布

    OpenCode 的推理档位现在对任何模型都能选择，选中后真正生效；新建或恢复会话不再重置已选档位。

    安装包 v0.28.1↗

  2. v0.24.1

    CodeBuddy 按模型显示可用推理档位，并调整了首页浏览器按钮间距。自 v0.17.0 以来还加入了 Codex CLI、内置浏览器、扩展中心和会话内切换 CLI。

    安装包 v0.24.1↗

  3. v0.17.0

    新增 Google Antigravity CLI（agy）支持。

    安装包 v0.17.0↗

  4. v0.16.9

    Bot 消息卡片改用与头像同色的圆点标识。

    安装包 v0.16.9↗

  5. v0.16.8

    收到的 Bot 消息显示发送者姓名，聊天中不再显示原始消息信封。

    安装包 v0.16.8↗

  6. v0.16.7

    Bot 之间的消息改用可读的卡片展示。

    安装包 v0.16.7↗

  7. v0.16.6

    macOS 使用同一个通用安装包，支持 Apple 芯片和 Intel Mac。

    安装包 v0.16.6↗

  8. v0.16.5

    恢复 Bot 之间互发消息，修复上下文重发和 CodeBuddy 回复被丢弃的问题。

    安装包 v0.16.5↗

  9. v0.16.4

    修复 Windows 窗口按钮失效，并去掉多余的右键菜单。

    安装包 v0.16.4↗

  10. v0.16.3

    Windows 的侧栏折叠按钮移入标题栏，侧栏标志上移。

    安装包 v0.16.3↗

  11. v0.16.2

    Windows 新增自绘菜单栏和卡片式内容区，修复 CodeBuddy 无法启动的问题。

    安装包 v0.16.2↗

  12. v0.16.1

    Windows 改用无边框窗口，macOS 引入通用安装包。

    安装包 v0.16.1↗

  13. v0.16.0

    提供 Windows 安装包，界面与 macOS 版保持一致。

    安装包 v0.16.0↗
